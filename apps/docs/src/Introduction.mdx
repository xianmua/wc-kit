# wc UI 组件库

基于 Web Components（Lit 3）的跨框架 UI 组件库，`wc` 前缀，一次编写、React / Vue / 原生 HTML 通用。

## 快速开始

```bash
pnpm add @wc/core
```

```ts
// 入口处引入：设计令牌 + reset + 全部组件注册
import '@wc/core/tokens.css';
import '@wc/core/reset.css';
import '@wc/core';
```

```html
<wc-button theme="primary">你好，wc</wc-button>
```

## 框架适配

| 框架 | 包 | 说明 |
| --- | --- | --- |
| React 18 / 19 | `@wc/react` | `@lit/react` 包装，事件映射为 `onWc*` props |
| Vue 3 | `@wc/vue` | GlobalComponents 类型增强 + v-model 适配说明 |

```tsx
// React
import { WcInput } from '@wc/react';

<WcInput label="用户名" clearable onWcChange={(e) => console.log(e.detail.value)} />;
```

```vue
<!-- Vue：原生 v-model 不适用，用 :value + 事件 -->
<wc-input :value="text" @wc-input="text = $event.detail.value" />
```

## 主题

通过 `setTheme('dark')` 切换（`data-theme` 属性驱动），全部语义令牌自动跟随。

## 组件总览

- **基础**：Button / Icon / Divider / Tag / Avatar / Space / Layout / Typography
- **表单**：Input / Textarea / Select / Checkbox / Radio / Switch / Slider / InputNumber / DatePicker / Form
- **反馈与导航**：Dialog / Drawer / Message / Tooltip / Popconfirm / Tabs / Breadcrumb / Pagination
- **数据展示**：Badge / Empty / Progress / Card / List / Table
